# Сайт арбітражного керуючого

Статичний сайт: чистий HTML + CSS + JS. Без бекенду, без збірки, без залежностей.
Основний дизайн — варіант 2 «Модерн». Два інші варіанти лишилися в репозиторії для порівняння.

```
├── index.html              ← ОСНОВНИЙ САЙТ (дизайн «Модерн»)
├── style.css
├── script.js
├── privacy.html            ← політика конфіденційності (чернетка)
├── assets/                 ← сюди покласти фото та картинку для месенджерів
├── variants/index.html     ← сторінка порівняння трьох макетів
├── design-1-classic/       ← вихідний макет «Класика»        (noindex)
├── design-2-modern/        ← вихідний макет «Модерн» до доопрацювання (noindex)
├── design-3-dark/          ← вихідний макет «Темний преміум» (noindex)
└── serve.ps1               ← локальний сервер, якщо немає Python
```

---

## Як подивитися

У теці проєкту:

```bash
python -m http.server 8080
```

Далі відкрити <http://127.0.0.1:8080/> — це основний сайт.
Порівняння макетів — <http://127.0.0.1:8080/variants/>.

Якщо Python недоступний:

```bash
powershell -ExecutionPolicy Bypass -File serve.ps1
```

### Режим перевірки заглушок

Додайте `?draft` до адреси — <http://127.0.0.1:8080/?draft> — і всі місця, які ще
треба заповнити, підсвітяться рожевою пунктирною рамкою. Те саме працює для
`privacy.html?draft`. Коли на сторінці не лишиться жодної рамки — можна публікувати.

У коді такі місця позначені атрибутом `data-ph`, а складніші — коментарем `ЗАМІНИТИ`.

## Що потрібно від керуючого перед публікацією

Нічого з цього не вигадано — усе стоїть як заглушка.

| Дані | Заглушка зараз | Де на сайті |
|---|---|---|
| Ім'я для шапки й футера | `Ім'я Прізвище` | `<title>`, шапка, футер, privacy |
| Повне ПІБ | `Прізвище Ім'я По батькові` | «Про мене», privacy |
| Номер і дата свідоцтва | `Свідоцтво № 0000`, `№ 0000 від 00.00.0000` | hero, «Про мене», футер, privacy |
| Рік початку практики | `0000` | «Про мене» |
| Регіон основної практики | `Києва й області` | «Про мене» |
| Освіта | `Назва університету, спеціальність, рік` | «Про мене» |
| Саморегулівна організація | `Назва організації арбітражних керуючих` | «Про мене» |
| Підвищення кваліфікації | `Назва програми, рік` | «Про мене» (рядок можна видалити) |
| Років практики / справ / млн грн | `00` / `000` / `00` | цифри під hero |
| Вартість супроводу | `від 00 000 грн` | блок «Вартість» |
| Телефон | `+380 (00) 000-00-00` та `tel:+380000000000` | шапка, контакти, футер, кнопка дзвінка, privacy |
| Email | `info@example.com` | контакти, футер, privacy, **`script.js`** (адреса для форми) |
| Telegram | `https://t.me/USERNAME` | контакти |
| Viber | `viber://chat?number=%2B380000000000` | контакти |
| Адреса офісу | `м. Київ, вул. Прикладна, 1, офіс 00` | контакти |
| Графік роботи | `Пн–Пт 9:00–19:00` | контакти |
| Фото | сіра заглушка «Фото» | «Про мене» |
| Домен і картинка для месенджерів | закоментовано в `<head>` | `index.html` |
| Строк зберігання даних, дата редакції | `00 місяців`, `00.00.0000` | `privacy.html` |

Також варто підтвердити, що це відповідає дійсності (зараз це формулювання з макета):
«24/7 звʼязок у складних ситуаціях», «справу веду сам, без передачі помічникам»,
«оплату супроводу можна розбити на етапи», строки етапів у блоці «Як це працює».

### Швидка заміна через PowerShell

```bash
Get-ChildItem . -Include index.html,privacy.html,script.js | ForEach-Object { (Get-Content $_.FullName -Raw -Encoding UTF8) -replace 'info@example\.com','pochta@domen.ua' | Set-Content $_.FullName -Encoding UTF8 -NoNewline }
```

> Файли зберігайте у **UTF-8**, інакше кирилиця перетвориться на «кракозябри».

### Фото

Покладіть фото в `assets/` і замініть блок `<div class="ph">…</div>` у розділі «Про мене»
на рядок, наведений у коментарі `ЗАМІНИТИ` над ним:

```html
<img class="ph" src="assets/photo.jpg" alt="Прізвище Ім'я По батькові, арбітражний керуючий">
```

Рекомендований розмір — вертикальне фото приблизно 800×1000 px.

## Форма зворотного зв'язку

Бекенду немає, тому форма формує лист і відкриває поштовий застосунок (`mailto:`).
Щоб заявки приходили без поштового клієнта, підключіть зовнішній обробник
(наприклад, Formspree) — місце позначене коментарем у `script.js`.

## Що вже враховано

- Перевірено на ширині 1440 px і 390 px; на телефоні — компактні картки послуг,
  таби на всю ширину, кнопки на всю ширину, плаваюча кнопка дзвінка, яка ховається над контактами й футером
- Блок «Вартість», реквізити в «Про мене», месенджери, два нові питання у FAQ
- Сторінка політики конфіденційності, посилання на неї з форми та футера
- `<title>`, `description`, Open Graph, favicon; старі макети закриті від індексації (`noindex`)
- Якщо JavaScript вимкнено, увесь текст усе одно видно
- `prefers-reduced-motion` — анімації вимикаються

## Чого ще немає

- Реальної відправки форми (див. вище)
- Карти проїзду, кейсів, відгуків — їх варто додавати лише з реальними даними
- Юридичні формулювання, строки й текст політики конфіденційності — **чернетка**.
  Перед публікацією їх треба звірити з чинною редакцією Кодексу України з процедур
  банкрутства та Закону України «Про захист персональних даних».

## Публікація

Підійде будь-який статичний хостинг: GitHub Pages, Cloudflare Pages, Netlify.
Публікувати достатньо `index.html`, `style.css`, `script.js`, `privacy.html` і теку `assets/`.
Теки `design-*` та `variants/` на бойовий сайт викладати не обовʼязково.

Після змін у `style.css` чи `script.js` збільште номер версії в посиланнях
(`style.css?v=2` → `?v=3`), щоб відвідувачі не бачили старої версії з кешу.
