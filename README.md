# Сайт арбітражного керуючого — три варіанти дизайну

Статичний сайт: чистий HTML + CSS + JS. Без бекенду, без збірки, без залежностей.
Кожен варіант самодостатній — обираєте один, решту тек видаляєте.

```
├── index.html              ← сторінка вибору (три варіанти поруч)
├── design-1-classic/       ← Варіант 1 «Класика»       — синій + золото, антиква
├── design-2-modern/        ← Варіант 2 «Модерн»        — світлий, смарагдовий
├── design-3-dark/          ← Варіант 3 «Темний преміум» — чорний + бронза
├── assets/                 ← сюди покласти фото
└── serve.ps1               ← локальний сервер, якщо немає Python
```

Кожна тека дизайну містить рівно три файли: `index.html`, `style.css`, `script.js`.

---

## Як подивитися

У теці проєкту:

```bash
python -m http.server 8080
```

Далі відкрити <http://127.0.0.1:8080/> — там сторінка з трьома варіантами.

Якщо Python недоступний, є запасний варіант на PowerShell:

```bash
powershell -ExecutionPolicy Bypass -File serve.ps1
```

> Просто відкрити `index.html` подвійним кліком (через `file://`) теж можна,
> але частина браузерів не підвантажує CSS із локального файлу — краще через сервер.

## Що замінити перед публікацією

Усі дані в макетах — **заглушки**. Ось повний перелік:

| Заглушка | Де зустрічається | На що замінити |
|---|---|---|
| `Ім'я Прізвище` | `<title>`, шапка, футер | Ім'я для відображення |
| `Прізвище Ім'я По батькові` | блок «Про мене» | Повне ПІБ |
| `+380 (00) 000-00-00` | шапка, контакти, футер | Основний телефон |
| `+380 (00) 000-00-01` | контакти | Другий телефон |
| `tel:+380000000000` | атрибути `href` | Телефон без пробілів і дужок |
| `info@example.com` | контакти, футер, **`script.js`** | Робоча пошта |
| `Свідоцтво № 0000 від 00.00.0000` | шапка, «Про мене», футер | Номер і дата свідоцтва |
| `м. Київ, вул. Прикладна, 1, офіс 00` | контакти | Адреса офісу |
| `0000` (рік) | «Про мене» | Рік початку практики |
| `00`, `000`, `00 млн` | блок цифр | Реальні показники |
| `Назва університету` | «Про мене» | Навчальний заклад |
| «Фото» | hero, «Про мене» | Див. наступний розділ |

### Швидка заміна через PowerShell

Замінює текст одразу в усіх файлах обраного дизайну:

```bash
Get-ChildItem design-2-modern -Include *.html,*.js -Recurse | ForEach-Object { (Get-Content $_.FullName -Raw -Encoding UTF8) -replace 'info@example\.com','pochta@domen.ua' | Set-Content $_.FullName -Encoding UTF8 -NoNewline }
```

> Файли зберігайте у **UTF-8**, інакше кирилиця перетвориться на «кракозябри».

### Фото

У макетах стоїть сіра заглушка. Щоб поставити справжнє фото — покладіть його в `assets/`
і замініть блок-заглушку на звичайний `<img>`:

```html
<!-- було -->
<div class="portrait__ph"> … </div>

<!-- стало -->
<img src="../assets/photo.jpg" alt="Прізвище Ім'я По батькові, арбітражний керуючий">
```

Рекомендований розмір — вертикальне фото приблизно 800×1000 px.
Місця заміни позначені коментарем `ЗАМІНИТИ` прямо в коді.

## Форма зворотного зв'язку

Бекенду немає, тому форма формує лист і відкриває поштовий застосунок
(`mailto:`). Це працює всюди, але виглядає не дуже елегантно на мобільних.

Щоб заявки приходили на пошту без поштового клієнта, підключіть будь-який
зовнішній обробник — місце для цього позначено коментарем у `script.js`.
Наприклад, через Formspree:

```html
<form id="form" action="https://formspree.io/f/ВАШ_ID" method="POST">
```

…і приберіть `e.preventDefault()` разом із блоком `mailto` у `script.js`.

## Що вже враховано

- Адаптив: перевірено на ширині 390 px, 820 px і 1440 px
- Мобільне меню, плаваюча кнопка дзвінка на телефонах
- Теги `<title>`, `description`, Open Graph для коректного вигляду в месенджерах
- Іконка вкладки (favicon) — вбудована, окремий файл не потрібен
- Якщо JavaScript вимкнено, увесь текст усе одно видно (важливо для пошуковиків)
- `prefers-reduced-motion` — анімації вимикаються для тих, кому вони заважають
- Плавна поява блоків, акордеон FAQ, підсвічування активного пункту меню

## Чого ще немає

- Сторінок «Політика конфіденційності» та «Публічна оферта» — для збору
  персональних даних через форму вони потрібні
- Реальної відправки форми (див. розділ вище)
- Карти проїзду, блогу, кейсів, відгуків
- Юридичні формулювання, строки й цифри в текстах — **чернетка**.
  Перед публікацією їх треба звірити з чинною редакцією
  Кодексу України з процедур банкрутства.
